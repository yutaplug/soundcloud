# Login with a SoundCloud token

1. Open [soundcloud.com](https://soundcloud.com) and sign in.
2. Press `F12` to open Developer Tools and select the **Application** tab.
3. Open **Storage → Cookies → https://soundcloud.com**.
4. Find the cookie named `oauth_token` and copy its **Value**.
5. Open `SoundCloudDesktop.exe` and paste the value into the login box.
